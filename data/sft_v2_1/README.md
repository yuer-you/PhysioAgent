# SFT v2.1 数据

v2.1 只使用 v2 已经暴露的开发错误进行小规模修复，不读取冻结最终测试：

- 继承 v2 的 700 条训练、150 条验证和 100 条开发测试；
- 训练集增加 30 条统计工具名稳定性样本；
- 训练集增加 30 条“只指定 order，不补截止频率”样本；
- 验证集分别增加 10 条语义相同、文本不同的样本。

最终规模：

```text
train.jsonl       760
validation.jsonl  170
test.jsonl        100（已查看过结果，只是开发测试）
```

生成器没有把三条失败问题原文复制进训练或验证数据，只学习其一般规则。

```bash
python scripts/generate_sft_data_v2_1.py
```
