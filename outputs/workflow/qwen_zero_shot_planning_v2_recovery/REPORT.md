# Qwen 多步规划 v2：保守恢复评测

## 结论

在不重新调用模型的情况下，对已保存的 v2 原始输出进行离线保守恢复：

- 原始严格端到端成功率：**18/20（90%）**
- 应用恢复：**2/20**
- 恢复后计划合法率：**20/20（100%）**
- 恢复后工程成功率：**20/20（100%）**

严格成绩仍然是 90%，不会因为恢复而被改写。100% 表示 Agent 工程层在保留审计记录的前提下成功完成了全部 20 条开发/集成任务。

## 恢复范围

恢复器只接受以下唯一可判定的结构：

1. 文本以一个仅含 `steps` 的 JSON 对象形式开始；
2. 最后的顶层 `}` 存在；
3. 忽略字符串内部字符后，最后 `}` 之前恰好只剩顶层 `{` 和 `steps` 的 `[` 未闭合；
4. 插入一个 `]` 后，完整文本必须通过原有严格 JSON、工具名、参数名、参数类型、步数上限和非空字符串校验。

它不会修复工具名、参数值、多余步骤、Markdown、任意截断文本或其他语义错误，也不会进行第二次猜测。

## 恢复案例

- `wf_load_stats_001`
- `wf_load_stats_002`

两条恢复后的计划都与人工期望严格一致，工具执行成功，真实数据参考检查通过，最终回答也包含真实工具结果。

## 指标解释

`strict_end_to_end_success_rate` 衡量模型原始输出能力，用于模型和提示词比较；`operational_success_rate` 衡量加入明确恢复策略后的 Agent 可用性，用于工程验收。两者必须同时报告，不能用后者代替前者。
